# Istilah kerja

[Kembali ke indeks](../README.md)

Definisi ini digunakan untuk menjaga konsistensi editorial dalam repositori, bukan menetapkan istilah universal semua profesi.

| Istilah | Makna dalam knowledge base |
| --- | --- |
| Portofolio | Kumpulan terkurasi informasi dan karya untuk membantu menilai kemampuan serta kecocokan pemiliknya. |
| Induk | Kelompok kebutuhan informasi utama; tidak sama dengan section halaman. |
| Positioning | Penjelasan ringkas tentang peran, fokus, dan konteks profesional. |
| Nilai yang ditawarkan | Bantuan atau manfaat yang dapat dituju melalui pekerjaan. |
| Core expertise | Kompetensi utama yang mendukung nilai dan karya. |
| Discipline | Bidang/prinsip pengetahuan yang mendasari praktik. |
| Selected work | Karya yang dipilih berdasarkan relevansi dan daya jelaskan. |
| Kontribusi | Bagian pekerjaan yang benar-benar dilakukan seseorang. |
| Case study | Penjelasan kontekstual tentang masalah, keputusan, pelaksanaan, dan hasil proyek. |
| Constraint | Batas nyata yang memengaruhi keputusan atau pelaksanaan. |
| Tradeoff | Pertukaran manfaat dan biaya/keterbatasan dalam suatu pilihan. |
| Output | Artefak atau pekerjaan yang dihasilkan. |
| Outcome | Perubahan yang diamati pada penggunaan atau keadaan setelah pekerjaan. |
| Dampak | Arti lebih luas dari perubahan terhadap tujuan yang relevan. |
| Baseline | Keadaan atau nilai awal untuk perbandingan. |
| Metrik | Ukuran yang definisi dan konteksnya jelas. |
| Klaim | Pernyataan yang ingin dipercaya pembaca. |
| Bukti | Materi/informasi yang mendukung pemeriksaan klaim tertentu. |
| Aspirasi | Arah atau capaian yang ingin dicapai, belum sama dengan fakta pencapaian. |
| CTA | Ajakan untuk melakukan langkah berikutnya yang konkret. |
| Preview | Representasi ringkas karya, misalnya gambar, video, cuplikan, atau demo. |
